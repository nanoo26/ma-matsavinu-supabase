# Debugging Workflow Prompt Template

## Problem Statement
[Describe bug, observed behavior, and expected behavior.]

## Safety Constraints
- Inspect first; do not patch blindly.
- Keep scope minimal.
- Avoid destructive operations.
- Preserve financial month logic unless explicitly in scope.

## Workflow
1. Reproduce issue with exact steps.
2. Trace impacted route/function/data path.
3. Gather logs/errors and failing conditions.
4. Propose root cause with concrete evidence.
5. Propose minimal fix and risk assessment.
6. Implement only after approval (if requested).
7. Validate with focused regression checks.

## Output
1. Reproduction
2. Root cause
3. Proposed fix
4. Validation results
5. Residual risk
